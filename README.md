# LRP1_heart

Heart Cell Atlas v2 데이터로 심장 세포의 LRP1과 sheddase 발현을 분석한다.

대상 유전자: LRP1 / ADAM10, ADAM12, ADAM17, MMP14, MMP15, MMP16, MMP17, BACE1

## 분석

### 1. 세포 유형별 LRP1, sheddase 발현
- 모든 세포 유형에서 유전자별 발현 세포 비율과 평균 발현량을 계산
- 섬유모세포가 다른 세포 유형보다 실제로 높은지 공여자 단위로 비교
- 결과: 도트 플롯, 세포 유형별 표

### 2. 섬유모세포의 발현 비율과 공여자 간 일관성
- 섬유모세포에서 유전자별 발현 세포 비율을 공여자마다 계산
- 세포/핵 측정 방식별로 나눠 확인
- 결과: 공여자당 점 하나인 상자 그림

### 3. 섬유모세포 집단별 비교
- 세부 집단(FB1~FB6)과 부위(심방, 심실)별 발현 비율 비교
- 결과: 집단별 도트 플롯

### 4. sheddase 간 비교
- 섬유모세포에서 어떤 sheddase가 가장 많이 발현되는지 순위화
- LRP1과 같은 세포에서 함께 검출되는 비율 계산
- 결과: sheddase별 막대 그림, 공동 검출 히트맵

### 5. 섬유모세포와 심근세포의 공간적 이웃 관계 (Visium)
- 조직 절편에서 섬유모세포 집단과 심근세포 집단의 위치 추정량을 비교
- 어떤 섬유모세포 집단이 어떤 심근세포 집단과 같은 자리에 있는지 확인
- 결과: 조직 절편 지도, 집단 간 공존 히트맵
